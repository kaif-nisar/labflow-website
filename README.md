LabFlow – Pathology Laboratory Management Software
About LabFlow

LabFlow is a modern pathology laboratory management software designed to simplify laboratory operations, patient handling, report generation, barcode management, and diagnostic workflows.

It helps pathology labs and diagnostic centers manage their daily tasks efficiently with a fast, secure, and user-friendly system.

Installation
Clone Repository
git clone https://github.com/yourusername/labflow.git
Open Project
cd labflow
Install Dependencies
npm install
Create Environment File

Create a .env file in the root directory.

Example:

PORT=5000
MONGODB_URI=your_mongodb_url
JWT_SECRET=your_jwt_secret
CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
Start Development Server
npm start
